## 1. Descrição do Projeto

O projeto "Animais Fantásticos" desenvolvido em conjunto com o curso da Origamid é uma aplicação web interativa e dinâmica, desenvolvida para explorar e apresentar informações sobre diversos animais de forma envolvente. Utilizando as melhores práticas do desenvolvimento front-end, este repositório serve como um excelente exemplo de como construir interfaces ricas em funcionalidades e com uma experiência de usuário aprimorada. Ele é ideal para entusiastas da fauna, estudantes de desenvolvimento web que buscam um projeto prático de JavaScript avançado, ou como um portfólio demonstrando habilidades em manipulação do DOM, consumo de APIs e modularização de código.

## 2. Arquitetura do Projeto

Este projeto é uma **Aplicação Frontend** robusta, focada na experiência do usuário e na interatividade. Não possui um backend próprio neste repositório, mas é projetado para consumir dados de APIs externas e arquivos JSON locais, demonstrando a capacidade de integrar-se a diferentes fontes de dados.

*   🌐 **Aplicação Frontend:** Construída com HTML, CSS e JavaScript puro, esta camada é responsável por toda a interface do usuário, lógica de interação, animações e requisições assíncronas para obter e exibir dados dinamicamente. O código JavaScript é modularizado e otimizado com Webpack para uma performance eficiente.
